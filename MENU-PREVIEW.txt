  SETUP GUIDE
  Foreign: name -> Cloudflare domain -> HTTPS ports -> target inbound
  -> MUX -> padding -> certificate.
  Iran: pairing code -> IP -> multiple client ports -> sessions ->
  padding -> ECH OFF / ECH ON / Fragment -> quota.
  Padding default: 0.22. V1 wire window: fixed 512 KiB.
  Memory budgets are not a process RSS cap.
  First test on new servers with your real Cloudflare domain.
  Existing 3.x/V3 installations and pairing codes are not compatible.
