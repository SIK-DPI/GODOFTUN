# 安全与公开包内容

[English](SECURITY.md) · [فارسی](SECURITY.fa.md) · [Русский](SECURITY.ru.md) · [首页](../README.zh-CN.md)

这里的 GODOFTUN V1.0.0 通过可读的安装器分发编译后的可执行文件。本页说明哪些内容仍然可见、哪些内容必须保密，以及测试不能证明哪些事情。

## 哪些内容隐藏了，哪些没有

| 内容 | 公开包中的情况 |
|---|---|
| 原始 Go 源代码和开发测试 | 不包含 |
| Bash 安装器和 shell 管理器 | 可读 |
| 四个 Python 管理辅助工具 | 在安装器内可读；安装后作为文件存放在服务器上 |
| Linux amd64 和 arm64 可执行文件 | 以可解码的 Base64 嵌入，并未加密 |
| Go 模块/构建元数据和链接符号 | 可以在可执行文件中检查 |
| 服务器生成的令牌、私钥、配对码和客户用量账本 | 不属于发布包；在部署期间创建或提供 |

编译不等于防复制。接收者可以提取并分析二进制文件；Base64 是打包方式，不是保密措施。删除注释或剥离符号不能保证代码隐蔽。Go 符号信息被保留，以支持有效的漏洞扫描。这是二进制分发，并不声称所有实现细节都已隐藏。

## 必须保密的文件

不要将所有者私有源码 ZIP、服务器备份以及以下部署文件放入公开仓库：

- `/etc/godoftun/tunnels/TUNNEL_ID/token`、`peer.env`、`deployment.env` 以及隧道配置目录。
- `/var/lib/godoftun/TUNNEL_ID/`，包括用量账本和状态快照。
- `/opt/godoftun/backups/`、证书私钥和管理员 SSH 凭据。
- 配对码、签名编辑码、客户导出文件，以及未脱敏的日志/截图。

配对码中包含令牌。签名编辑码经过身份验证，但没有加密，可能包含敏感值。拥有服务器 root 权限的人可以读取已安装的文件；文件权限无法对该管理员隐藏这些内容。不要上传整个所有者输出文件夹：只使用公开 ZIP 或 `PUBLIC_GITHUB` 中的内容。

附带的 `.gitignore` 有助于防止误添加，但不能清除已经提交的秘密。发布前，请检查暂存文件和仓库历史。如果秘密已经泄露，应消除暴露来源，并轮换受影响的凭据；仅删除帖子不等于完成轮换。请使用[编辑器](CONFIGURATION.zh-CN.md)协调两端的隧道令牌变更，并预期在共享设置不一致期间出现中断。

## 信任与访问边界

Cloudflare 会终止外层 TLS 连接。如果应用内容需要对中间方保密，请使用恰当的应用层加密和身份验证。伊朗接入端口或客户配额不等于 Xray UUID/密码。如果目标应用允许访问，知道其他可达入口的人可以使用那个入口的配额。

境外目标和 WSS 后端应保持在回环接口上。检查公网防火墙规则和服务商规则。绝不要将隧道令牌作为客户端凭据公开，也不要通过关闭 TLS 验证来绕过安装失败。

安装器需要 root 权限，并且能够安装软件包、创建服务账户、写入 Nginx/systemd 配置、在已启用的 UFW 上开放规则、签发证书以及启动服务。其回滚机制保护的是跟踪到的文件，而不是每一种可能的系统变化。请使用专用测试服务器并保留私有备份；参阅[运维指南](OPERATIONS.zh-CN.md)。

## 外部网络访问

正常运行时会连接已配置的境外端点。安装期间还会访问系统软件包仓库、Cloudflare IP 地址范围 API；当本地公网 IP 检测不足以确定地址时，还可能访问 `api.ipify.org`。自动证书签发会使用 Certbot 的 CA 服务。ECH 发现使用配置的 DoH 解析器；默认依次为 `cloudflare-dns.com` 和 `dns.google`。这些是运行依赖，并不意味着部署能够离线运行，或对这些服务不可见。

## 验证与局限

运行安装器前，请使用可信发布中的 `SHA256SUMS` 验证文件。安装器还会检查嵌入的二进制文件哈希和预期版本。校验和不是数字签名，无法同时认证由攻击者控制的下载文件与清单。

请阅读[验证结果](../VALIDATION.md)，了解实际执行的测试以及尚未完成的 Linux/Cloudflare 检查。没有告警的扫描无法证明不存在任何漏洞。ECH、填充和 Fragment 不保证匿名性、抗审查能力或特定速度。服务显示为 “Active” 以及传输连接握手成功，都不是完整的应用测试。
