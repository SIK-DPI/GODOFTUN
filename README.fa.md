# GODOFTUN V1.0.0

تونل TCP مولتی‌پورت، با دامنهٔ خارجی پشت پروکسی کلودفلر و اتصال کاربران به IP و پورت ایران.

[English](README.md) · [简体中文](README.zh-CN.md) · [Русский](README.ru.md) · [کانال SIKDPI](https://t.me/SIKDPI)

## راهنماها

پیش از اجرای نصاب، نصب و تنظیم کلودفلر را بخوانید. مقادیر نمونه را با اطلاعات واقعی سرور خودتان جایگزین کنید.

| راهنما | موضوع |
|---|---|
| [نصب](docs/INSTALLATION.fa.md) | پیش‌نیازها، بررسی فایل، نصب خارج و ایران، تنظیم کلاینت و فهرست تست نهایی |
| [کلودفلر](docs/CLOUDFLARE.fa.md) | DNS، پروکسی روشن، پورت، WebSocket، گواهی origin، تمدید و ECH |
| [تنظیمات](docs/CONFIGURATION.fa.md) | پیش‌فرض‌ها، محدودیت‌ها، MUX، padding، session، stream، حافظه، TLS و ویرایش دو طرف |
| [مدیریت](docs/OPERATIONS.fa.md) | مرجع دستورها، پورت و سهمیهٔ مشتری، پایش، انتقال فایل، پشتیبان، ارتقا و حذف |
| [رفع خطا](docs/TROUBLESHOOTING.fa.md) | Doctor، خطاهای متداول، بازیابی و گزارش امن برای پشتیبانی |
| [امنیت](docs/SECURITY.fa.md) | کد قابل‌مشاهده، نگه‌داری رازها، مرز اعتماد و محدودیت انتشار |

هر شش راهنما در چهار زبان بالا موجود است. دستورها و رابط ترمینالی برنامه همچنان انگلیسی‌اند. [گزارش تست‌ها](VALIDATION.md) نتیجهٔ تست محلی را از تست‌های اجرا‌نشدهٔ لینوکس و مسیر واقعی کلودفلر جدا می‌کند.

## شروع سریع

کل ZIP عمومی را استخراج و وارد پوشهٔ `sik-dpi` شوید. فایل مستقل `GODOFTUN-V1.0.0.sh` را از همان انتشار مورد اعتماد بردارید. در لینوکس پیش از اجرا همهٔ فایل‌ها را بررسی کنید:

```bash
sha256sum -c SHA256SUMS
```

روی macOS از `shasum -a 256 -c SHA256SUMS` استفاده کنید. checksum وقتی هم فایل و هم فهرست را مهاجم داده باشد، اصالت را ثابت نمی‌کند.

دیدن منو بدون نصب و بدون نیاز به root:

```bash
bash GODOFTUN-V1.0.0.sh preview
```

ابتدا روی سرور **خارج**:

```bash
sudo bash GODOFTUN-V1.0.0.sh foreign
```

سپس روی **ایران** اجرا کنید و کد اتصال محرمانهٔ خارج را وارد کنید:

```bash
sudo bash GODOFTUN-V1.0.0.sh iran
```

فایل نصب، باینری‌های Linux amd64 و arm64 را همراه دارد؛ روی سرور Go لازم نیست. محیط هدف Ubuntu/Debian با systemd و IPv4 عمومی است. نصب وابستگی‌هایی مثل Nginx ممکن است به دریافت بسته نیاز داشته باشد. کپی نصاب به معنی استقرار کاملاً آفلاین نیست؛ DNS، تأیید پروکسی کلودفلر و مسیر تونل باید در دسترس باشند. این برنامه فقط TCP است، نه تونل UDP یا VPN کل دستگاه.

## امکانات

- فقط WSS و دامنهٔ خارجی با پروکسی روشن کلودفلر؛ بدون گزینهٔ آروان یا دامنهٔ ایران.
- چند پورت ورودی و چند تونل نام‌دار.
- MUX روشن/خاموش، کنترل Session و Stream و حافظهٔ صف.
- Padding بایتی با پیش‌فرض ۰٫۲۲، ECH سخت‌گیرانه یا Fragment.
- ویرایش هماهنگ دو طرف، سهمیهٔ پورت مشتری‌ها و عیب‌یابی.
- رابط ترمینالی فیروزه‌ای با بخش‌های تونل‌ها، تنظیمات، مشتری‌ها و عیب‌یابی؛ نصب مرحله‌به‌مرحله.

پنجرهٔ جریان این V1 ثابت و ۵۱۲ کیبی‌بایت است؛ کنترل تطبیقی نسخهٔ ۳.۵ منتقل نشده است. V1 را با نصب و کد اتصال ۳.x مخلوط نکنید.

## رابط ترمینال

اسکریپت را بدون آرگومان برای منوی اصلی، یا پس از نصب با `manage` اجرا کنید. دستور `preview` فقط منوها را نشان می‌دهد؛ بدون root، بررسی شبکه، تغییر سرور یا وضعیت زندهٔ ساختگی.

برای ترمینال روشن `GODOFTUN_THEME=light` و برای زمینهٔ تیره `GODOFTUN_THEME=dark` (پیش‌فرض) را قبل از دستور قرار دهید. `NO_COLOR=1` رنگ را خاموش می‌کند؛ خروجی فایل و `TERM=dumb` هم خودکار بدون رنگ‌اند. منوها در عرض کم شکسته می‌شوند؛ `COLUMNS=60` عرض ۶۰ ستونی را تنظیم می‌کند. شمارهٔ گزینه‌ها و تأییدهای قبل از تغییر حفظ شده‌اند.

## دربارهٔ انتشار

این مخزن **توزیع باینری** است، نه سورس‌باز. سورس Go در بسته نیست؛ خود نصب‌کننده و ابزارهای مدیریتی Bash/Python قابل خواندن‌اند. باینری هم قابل بررسی و مهندسی معکوس است؛ ادعای مخفی‌سازی کامل نداریم.

[نتیجهٔ تست‌ها](VALIDATION.md) را بخوانید و قبل از استفادهٔ عمومی، نصب واقعی Linux و مسیر کلودفلر را روی سرورهای تمیز خودتان تست کنید. token، کلید خصوصی، کد اتصال/ویرایش و مصرف مشتری‌ها را منتشر نکنید.

شرایط استفاده و بازتوزیع پروژه باید پیش از انتشار به تأیید مالک برسد. مجوزهای وابستگی‌ها در `THIRD_PARTY_LICENSES/` آمده‌اند. [قدردانی](ACKNOWLEDGMENTS.md)
