# GODOFTUN V1.0.0

Многопортовый TCP-туннель: зарубежный домен работает через прокси Cloudflare, а пользователи подключаются к IP-адресу и порту сервера в Иране.

## Загрузка и запуск

Распакуйте весь публичный ZIP и перейдите в папку `sik-dpi`. Используйте самостоятельный установщик `GODOFTUN-V1.0.0.sh` из того же доверенного выпуска. В Linux сначала проверьте все файлы:

```bash
sha256sum -c SHA256SUMS
```

В macOS используйте `shasum -a 256 -c SHA256SUMS`. Контрольная сумма не подтверждает подлинность, если злоумышленник подменил и файл, и список сумм.

Просмотр меню без установки:

```bash
bash GODOFTUN-V1.0.0.sh preview
```

На чистом тестовом сервере сначала установите зарубежную сторону:

```bash
sudo bash GODOFTUN-V1.0.0.sh foreign
```

Затем запустите установщик в Иране и вставьте конфиденциальный код сопряжения:

```bash
sudo bash GODOFTUN-V1.0.0.sh iran
```

Установщик содержит исполняемые файлы Linux amd64 и arm64; Go на целевых серверах не нужен. Целевая среда — Ubuntu/Debian с systemd и публичным IPv4. Для зависимостей, например Nginx, может потребоваться загрузка пакетов. Копирование установщика не делает развёртывание полностью автономным: DNS, проверка прокси Cloudflare и маршрут туннеля должны быть доступны. Поддерживается только TCP, а не UDP или VPN для всего устройства.

## Возможности

- Зарубежный домен с включённым прокси Cloudflare; только WSS.
- Несколько клиентских портов и именованных туннелей.
- Включение и отключение MUX, ограничения сессий, потоков и удерживаемых буферов.
- Байтное заполнение padding со значением по умолчанию 0.22; строгий ECH либо фрагментация ClientHello.
- Согласованное редактирование двух сторон, квоты клиентских портов и диагностика.
- Бирюзовые терминальные меню Tunnels, Tuning, Customers и Doctor с пошаговой установкой.

Arvan, прямой зарубежный режим и домен на иранской стороне не предлагаются. V1 сохраняет фиксированное окно управления потоком 512 KiB; адаптивного контроллера версии 3.5 здесь нет. Не смешивайте установки и коды сопряжения V1 и 3.x.

## Терминальный интерфейс

Запустите установщик без аргументов для главного меню или с `manage` после установки. Команда `preview` показывает меню без root, сетевых проверок, изменений сервера и выдуманных показателей состояния.

Выберите акцентные цвета для тёмного или светлого терминала через `GODOFTUN_THEME=dark` (по умолчанию) либо `GODOFTUN_THEME=light`. `NO_COLOR=1` отключает цвет; вывод в файл и `TERM=dumb` автоматически используют обычный текст. Меню переносят строки при небольшой ширине; `COLUMNS=60` задаёт 60 столбцов. Номера действий и подтверждения сохранены.

## Исходный код и безопасность

Это **бинарный дистрибутив**, а не репозиторий с открытым исходным кодом. Реализация на Go не включена. Установщик и встроенные управляющие скрипты Bash/Python доступны для чтения; исполняемые файлы также поддаются анализу. Полное сокрытие кода не обещается.

Перед предоставлением доступа пользователям изучите [результаты проверок](VALIDATION.md), выполните реальную установку Linux и проверьте маршрут Cloudflare на своих чистых серверах. Не публикуйте token, закрытые ключи, коды сопряжения и изменений или файлы учёта клиентов.

Условия распространения самого проекта ещё требуют утверждения владельца. Лицензии зависимостей находятся в `THIRD_PARTY_LICENSES/`. См. [благодарности](ACKNOWLEDGMENTS.md).
